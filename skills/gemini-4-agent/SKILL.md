## Two Execution Modes & Token Quota Mechanics

### Mode 1: Full Autonomous Agent Loop (100% Web Quota, 0 Antigravity Tokens)
If you want Gemini 4 Neon to act as the primary autonomous agent (reading files, executing bash, editing code) using **only your Google AI Pro web quota**:

Run the autonomous runner:
```bash
python3 scripts/gemini_agent.py "<task_description>" --model neon --effort xhigh
```

Features:
- Executes multi-turn tool loops autonomously (`bash`, `read_file`, `write_file`, `edit_file`, `list_dir`).
- Every thought, plan, and tool invocation is generated by Gemini Web.
- Zero Antigravity IDE tokens consumed.

### Mode 2: MCP Tool Consultation (Hybrid Mode)
If you are already conversing with Antigravity and want second-opinion planning from Gemini 4 Neon:
- Call `gemini-4-gateway` MCP tool: `gemini_4_neon` or `gemini_4_carbon`.
- Neon generates the deep architectural blueprint using Web quota.
- Antigravity receives the plan and executes local changes.
